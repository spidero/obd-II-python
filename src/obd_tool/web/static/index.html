On-board monitor tests

The ECU tests the catalyst, O2 sensors, EGR and misfires by itself while you drive. These are its measured values against its own limits (OBD mode 06) — a test close to the limit shows a part wearing out before a trouble code appears.

Click “Read test results”.

Vehicle health check

Reads trouble codes and readiness monitors, samples live data and rates the car's condition: charging, cooling, fuel mixture, idle, O2 sensors and catalyst. For best results run it with the engine running, warm (>70 °C) and idling.

What is kept here

Each vehicle has its own dashboard layout and history: health reports, the codes and freeze frame saved automatically before clearing, and saved trips. Tick two health reports to compare them, for example before and after a repair.

Clear trouble codes?

Clearing (mode 04) erases stored and pending codes and freeze frame data, and resets the readiness monitors and monitor test results. Until the monitors complete again (a few drive cycles) the car may fail an emissions inspection.

If the fault is still present, the code will come back. The codes and the freeze frame are saved to the History tab first.
